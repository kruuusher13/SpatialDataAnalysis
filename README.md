# Spatial Data Analysis

This repository contains materials for a spatial data analysis project, likely from a course or workshop. The project is divided into two main parts: Lab 1 and Lab 2.

## Lab 1: Data Retrieval, CRS, and Geodata Quality

This lab focuses on the fundamentals of handling spatial data. Key topics include:

*   **Data Retrieval:** Fetching data from sources like OpenStreetMap (OSM).
*   **Coordinate Reference Systems (CRS):** Understanding and managing different CRSs.
*   **Geodata Quality:** Assessing the completeness and accuracy of spatial datasets.

The `lab_1` directory contains various shapefiles (`.shp`), Python scripts, and other data related to these topics.

## Lab 2: Areal Interpolation and Land Use Analysis

This lab explores more advanced spatial analysis techniques. The main components are:

*   **Areal Interpolation:** Estimating data for one set of polygons from another, overlapping set.
*   **Land Use Analysis:** Analyzing land use patterns using datasets like `GRONDGEBRUIK_2017`.
*   **Demographic Analysis:** Working with demographic data, such as the `migrants.csv` file.

The `Lab_2` directory contains Jupyter Notebooks (`.ipynb`) with the analysis, as well as the data files used.

## Data

The data used in this project is located in the `lab_1` and `Lab_2/data` directories. It includes:

*   Shapefiles (`.shp`)
*   GeoPackage files (`.gpkg`)
*   CSV files (`.csv`)

Please refer to the notebooks and scripts in each lab's directory for details on how the data is used.
